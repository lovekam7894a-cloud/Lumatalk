# LumaTalk starter
ต้นแบบเว็บแอปโซเชียลภาษาไทยแบบ responsive

## วิธีทดลองบนมือถือ
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์ `index.html` ไปยัง repository บน GitHub
3. เข้า Settings > Pages
4. ใน Build and deployment เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/ (root)` แล้วกด Save
6. รอสักครู่ แล้วเปิด URL ที่ GitHub Pages แสดง

## ข้อจำกัดของต้นแบบ
- หน้าเว็บและปุ่มเป็นเดโมฝั่งเครื่อง ยังไม่ใช่ระบบออนไลน์หลายคน
- ข้อความยังไม่ถูกบันทึก/ส่งไปยังผู้ใช้อื่น
- ห้องเสียงยังไม่เชื่อมไมโครโฟนหรือ WebRTC
- เหรียญเป็นแต้มทดลอง ไม่มีการชำระเงินจริง
- ขั้นต่อไปต้องเพิ่ม backend/auth/database และระบบเสียง พร้อมมาตรการความปลอดภัย
